Payroll calculators, embedded in a plain HTML file

One script tag, then ordinary markup. Every figure below is computed in the browser from the same statutory rate tables the PHP package uses, and every one of them will show you its working.

The bundle has not been built yet. Run npm install && npm run build inside packages/payroll-js and reload - or swap the script tag for the unpkg URL in the comment above, which needs no build at all.

Mode C - a custom elementno javascript

Write the tag. That is the entire integration. The widget renders into a shadow root, so this page's serif body font and cream background cannot reach inside it, and its styles cannot escape onto this page. 

<payroll-gratuity-calculator></payroll-gratuity-calculator>

Starting values as attributes

Every field can be seeded from an attribute - the field name in kebab-case. Useful when the surrounding page already knows something about the visitor. 

<payroll-pf-calculator basic-salary="52000" employer-restricts-to-ceiling="false"></payroll-pf-calculator>

The data-payroll formfor cms editors

Plenty of WYSIWYG editors strip tags they do not recognise but leave a div alone. This form survives them. 

<div data-payroll="esi-calculator" gross-wages="17777"></div>

Theming

Custom properties are the supported surface. Set them on the element - or on any ancestor - and the widget picks them up. 

.branded { --payroll-accent: #7a3ea8; --payroll-radius: 2px; }

A document rather than a calculatorgst

The invoice generator is the same deal: one tag, no build step. Change the place of supply to a state other than Karnataka and watch the tax move from CGST plus SGST to a single IGST line - that switch follows from the place of supply and is not a setting anyone gets to choose. 

<payroll-invoice-generator buyer-state="Maharashtra"></payroll-invoice-generator>

Mode B - the same bundle, used as a library

The global Payroll carries every calculator, so a page can compute a figure without rendering a widget at all. Below is the result of calling it directly, written into the page by the script at the bottom of this file. 

const { gratuity, workings } = Payroll.calculateGratuity({
  lastDrawnSalary: 45000,
  yearsOfService: 7,
  monthsOfService: 7,   // more than six months rounds the year up
});

Listening to a widget

Each widget dispatches payroll:result every time it recalculates, so the host page can mirror a figure, log it, or send it onward.
